- Nitrox: narrative says two optional ocean dives cost extra, but the session label reads “Tank Analysis & 2 Ocean Dives”. Docs state the narrative clearly and require the dive-inclusive total to be confirmed; no silent promise of inclusion.
- Refresher: the landing-page cart defaults to an ocean-inclusive package, while course-beacon lists a pool-only base price. Preserve the distinction.
- Avelo Instructor: local older four-day program wording differs from current agency Essentials Instructor requirements. Do not quote an intake/version without confirming it.
- Course widget: initial 50-row page has a JavaScript pagination offset of 5. The updater uses the widget’s own AJAX endpoint with an explicit 50-row offset, validates the declared total and both page sizes, and rejects duplicate booking IDs.
- 95 listings were extracted and every exact booking URL returned a selected booking page. Coverage at audit: 3 October 2026 through 19 December 2027. There are 15 entries with first-session dates outside the main course date range. All are flagged for confirmation, including possible legitimate IDC preparation sessions.

## Operation and recovery

- Workflow: `.github/workflows/sync-helpscout-courses.yml`. Daily `30 2 * * *` with IANA timezone `Australia/Sydney`; GitHub may delay dispatch. On the spring-forward day GitHub advances a nonexistent 02:30 to its next valid time. Sydney-local-date check in the published article prevents duplicate daily publication, including autumn clock changes.
- The 42-article pack publishes only when its content hash changes. Full originals are saved as a workflow artifact before any update. Existing IDs/slugs/categories are preserved; new subjects receive new articles. Drafts, identity mismatches and concurrent changes stop writes.
- Date candidates are validated before publication: full declared count/pages, dates, course-name/path mapping, exact selected-cart identity, link response, capacities, prices and major count/price changes.
- Daily publication changes only the schedule body, then reads it back. A failed extraction/validation leaves the last good Docs body and JSON unchanged. Failure status is committed even if the job fails; GitHub marks the run failed. GitHub notification delivery depends on repository notification settings; no new email recipients were configured.
- Snapshot expires 48 elapsed hours after successful checking. The article includes an explicit ISO expiry and live-listing fallback. AI freshness behaviour requires acceptance testing; API publication alone is not evidence of Agent uptake.
- Raw candidates and readback evidence are workflow artifacts; the verified snapshot and status are versioned in `data/`. Rollback of knowledge uses the saved original article bodies with their IDs; do not delete/recreate the collection.
- If new course names, packages or website markup change, review the mapping/parser and rerun tests before enabling publication. No unknown course is silently skipped.

- Local test suite: 71 tests passed, including bad dates/prices/capacity, duplicate IDs, timetable conflicts, DST expiry, article identity/draft conflicts, readback and local-day deduplication.
- Live dry run: 95/95 rows, 50 + 45 rows across two pages; exact booking links verified.
- Production publication: workflow run [36724815938](https://github.com/abyss-scuba/abyss-future-dive-feed/actions/runs/36724815938) succeeded. Status records 95 listings across six schedule articles, all published and read back, checked at 2026-09-30T23:52:40.353+10:00. The 42 evergreen articles were published and read back in the earlier successful deployment; the original 20 article IDs were retained.
- Agent uptake: the prepared `Abyss Sydney Course Adviser` (27358) retrieved the new specialty schedule and correctly answered the date-specific October buoyancy question with Sunday 11 October 2026, listed AUD299 and booking ID 41406453. It also retrieved the revised Nitrox article and explained optional, extra-cost ocean dives. The Divemaster internship test recognised a qualifying 18-month-old First Aid/CPR certificate as still within the 24-month period, and distinguished the approved 20-dive internship entry from 60 dives to certify.
- Stale-data test: the Agent declined to confirm current price/availability from a three-day-old snapshot. An unrelated-link response was observed; the Agent's applied identity now instructs it to ask which course or use the general live listings instead of unrelated course links. That wording change is configuration evidence, not a claim of comprehensive regression coverage.
- Remaining launch limitation: a combined goal, prerequisites and October date question still sometimes retrieves the correct course recommendation but only a general booking URL. A separate date-specific question has retrieved the exact dated booking successfully. Do not present this as proven one-turn booking performance. Tune and test the full conversation, no-course-needed path, package/language distinctions, stale fallback and conversion tracking before connecting a public Beacon.
- Public deployment: the Agent is prepared for testing; the training-hub Beacon has not been connected by this work. Booking conversion uplift has not been measured.
